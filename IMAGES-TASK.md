# Иллюстрации курса

Растровые сцены сделаны в 3D-стиле. Надписи в обучающих блоках размещены в HTML/CSS поверх изображений, поэтому их можно точно править и читать на мобильном экране.

| Файл | Использование |
| --- | --- |
| `assets/hero-stop-standard-v3.png` | Обложка: один руководитель останавливает нарушение, без девушки с подносом |
| `images/domino-beef-thinking-v3.png` | Вступительная цепочка: руководитель обдумывает риск, без эмблемы |
| `images/expired-soap-kf-v3.png` | КФ «Просроченное мыло для рук»: руководитель в форме АУП без эмблемы |
| `images/feedback-later-v3.png` | Сравнение: обратную связь отложили, серьёзные лица, белая упаковка картошки |
| `images/feedback-now-v3.png` | Сравнение: обратную связь дали сразу, белая упаковка картошки |
| `images/fpr-fries-feedback-v3.png` | Разбор ФПР: корзина извлечена до сигнала, под ней чистый сухой поддон |
| `images/three-actions-pan-v3.png` | Наблюдение → замер котлет в пэне → повторная проверка; фартук сотрудницы от талии |

На кухне сотрудники носят чёрные полупрозрачные мелкоячеистые сетки. Форма ЧБР: чёрное поло с белой кокеткой, широкой оранжевой и красной полосами, длинный чёрный фартук с пламенем от талии. На иллюстрациях форма АУП: чёрная рубашка без эмблемы и без фартука. Источник: `Обновленные курсы/ku-design-system/photo-refs/burger_king_reference_catalog.ru.json` и `burger_king_style_3d_animation.ru.json`.
