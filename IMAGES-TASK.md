# Иллюстрации курса

Растровые сцены сделаны в 3D-стиле. Надписи в обучающих блоках размещены в HTML/CSS поверх изображений, поэтому их можно точно править и читать на мобильном экране.

| Файл | Использование |
| --- | --- |
| `assets/hero-domino-plain.png` | Обложка: руководитель без головного убора останавливает обычное домино |
| `images/domino-beef-thinking.png` | Вступительная цепочка: замер котлеты, пропущенное отклонение, расстроенный Гость |
| `images/expired-soap-kf.png` | КФ «Просроченное мыло для рук» в листалке |
| `images/feedback-later.png` | Сравнение: обратную связь отложили |
| `images/feedback-now.png` | Сравнение: обратную связь дали сразу |
| `images/fpr-fries-feedback.png` | Разбор ФПР на примере картошки перед аудио |
| `images/three-actions-pan.png` | Пятиминутка → замер котлет в пэне на стойке борта → повторная проверка |

На кухне сотрудники носят чёрные полупрозрачные мелкоячеистые сетки. Форма ЧБР: чёрное поло с белой кокеткой, широкой оранжевой и красной полосами, длинный чёрный фартук с пламенем. Форма АУП: чёрная рубашка с маленькой полосатой нашивкой. Источник: `Обновленные курсы/ku-design-system/photo-refs/burger_king_reference_catalog.ru.json` и `burger_king_style_3d_animation.ru.json`.
