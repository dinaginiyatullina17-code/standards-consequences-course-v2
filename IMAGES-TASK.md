# Иллюстрации курса

Растровые сцены сделаны в 3D-стиле. Надписи в обучающих блоках размещены в HTML/CSS поверх изображений, поэтому их можно точно править и читать на мобильном экране.

| Файл | Использование |
| --- | --- |
| `assets/hero-stop-standard.png` | Обложка: руководитель останавливает передачу продукта, без домино |
| `images/domino-beef-thinking-v2.png` | Вступительная цепочка: руководитель обдумывает риск, не улыбается |
| `images/expired-soap-kf-v2.png` | КФ «Просроченное мыло для рук»: мужчина в форме АУП |
| `images/feedback-later-v2.png` | Сравнение: обратную связь отложили, белая упаковка картошки |
| `images/feedback-now-v2.png` | Сравнение: обратную связь дали сразу, белая упаковка картошки |
| `images/fpr-fries-feedback-v2.png` | Разбор ФПР: сотрудница достаёт картошку до сигнала, руководитель останавливает её |
| `images/three-actions-pan-v2.png` | Наблюдение за рестораном → замер котлет в пэне с ручкой → повторная проверка |

На кухне сотрудники носят чёрные полупрозрачные мелкоячеистые сетки. Форма ЧБР: чёрное поло с белой кокеткой, широкой оранжевой и красной полосами, длинный чёрный фартук с пламенем. Форма АУП: чёрная рубашка с маленькой полосатой нашивкой. Источник: `Обновленные курсы/ku-design-system/photo-refs/burger_king_reference_catalog.ru.json` и `burger_king_style_3d_animation.ru.json`.
