# Иллюстрации курса

Иллюстрации сгенерированы для этой версии курса. Текст обратной связи на сцене с мокрым полом наложен в HTML/CSS, чтобы его можно было точно редактировать и читать на разных экранах.

| Файл | Где используется |
| --- | --- |
| `assets/hero-violations-3d-v3.png` | Обложка: руководитель останавливает домино в цепочке замера котлеты |
| `images/domino-beef-chain.png` | Компактная цепочка «котлета ниже 68 °C → пропущенное отклонение → риск отравления» |
| `images/risk-chain-shift-v2.png` | Нарушение личной гигиены: мыло у раковины |
| `images/wet-floor-feedback.png` | После разбора ФПР: уборка пола без таблички; текст обратной связи в `index.html` |
| `images/control-system-cycle-v2.png` | Пятиминутка и замер котлеты на стойке борта, со щупом и секундомером |

Для всех сотрудников на производстве: волосы и уши закрыты шапочкой; на сценах у фритюра и при замере перчаток нет. Иллюстрации не содержат текст внутри растровых файлов.
