# Иллюстрации курса

Растровые сцены сделаны в 3D-стиле. Надписи в обучающих блоках размещены в HTML/CSS поверх изображений, поэтому их можно точно править и читать на мобильном экране.

| Файл | Использование |
| --- | --- |
| `assets/hero-stop-standard-v3.png` | Обложка: один руководитель останавливает нарушение, без девушки с подносом |
| `images/domino-beef-thinking-v3.png` | Вступительная цепочка: руководитель обдумывает риск, без эмблемы |
| `images/expired-soap-kf-v5.png` | КФ «Просроченное мыло для рук»: руководитель без фартука, сотрудница в фартуке от груди до колен |
| `images/feedback-later-v5.png` | Сравнение: прежняя сцена с фритюром, серьёзные лица, белая упаковка, фартук закрывает грудь и ноги |
| `images/feedback-now-v5.png` | Сравнение: прежняя сцена с фритюром, белая упаковка, фартук закрывает грудь и ноги |
| `images/fpr-fries-feedback-v6.png` | Разбор ФПР: напольная фритюрница с металлическими ручками корзин и передними панелями управления; волосы под сеткой |
| `images/three-actions-pan-v5.png` | Наблюдение → замер котлет в пэне → повторная проверка; у сотрудницы полный фартук от груди до колен |

На кухне сотрудники носят чёрные полупрозрачные мелкоячеистые сетки; волосы полностью убраны под сетку. Форма ЧБР: чёрное поло с белой кокеткой, широкой оранжевой и красной полосами, длинный чёрный фартук с пламенем от груди до колен, не доходящий до воротника. На иллюстрациях форма АУП: чёрная рубашка без эмблемы и без фартука. Источник: `Обновленные курсы/ku-design-system/photo-refs/burger_king_reference_catalog.ru.json` и `burger_king_style_3d_animation.ru.json`.
